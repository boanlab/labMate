# QA — 회귀 검증

실제 브라우저(Playwright/Chromium)로 5개 페르소나(지도교수·박사과정·석사과정·학부연구생·권한위임)의
업무 흐름을 재현하고 화면·접근성·레이아웃·보안을 확인한다. 매번 새 DB 를 전제하지 않고
(전제 데이터가 있어야 통과하는 검증이 섞여 있다), 축적된 데이터가 있는 로컬 스택에서 손으로 돌린다.

## 실행

스택이 떠 있어야 한다(`make up`).

```bash
make qa-seed   # 페르소나 계정 생성(최초 1회)
make qa        # 전체 회귀
```

저장소 루트를 거치지 않으려면:

```bash
cd qa
npm ci && npx playwright install --with-deps chromium
node scripts/setup-users.mjs      # LM_ADMIN_EMAIL / LM_ADMIN_PW 필요
./run-all.sh
```

하나라도 실패하면 0이 아닌 값으로 끝난다. 전체 로그 `out/regress.log`, 스크린샷 `out/shots/`.

| 환경변수 | 뜻 | 기본값 |
|---|---|---|
| `LM_BASE` | 검사 대상 주소 | `http://localhost:8080` |
| `LM_ADMIN_EMAIL` / `LM_ADMIN_PW` | 관리자 계정(설정 전환이 필요한 검증용) | `../.env` 에서 읽음 |
| `LM_OUT` | 산출물 위치 | `qa/out` |

## 검증 범위

| 묶음 | 확인 내용 |
|---|---|
| 라우트 크롤 | 5 페르소나 × 27 화면의 콘솔·HTTP 오류, 권한별 메뉴 노출 |
| 업무 시나리오 1·2 | 로그인 → 과제 등록 → 업무 배정 → 근태 → 연구노트 → 결재 순서 재현 |
| 뷰포트 스윕 | 13개 폭 × 27 화면의 가로 넘침·요소 이탈·텍스트 잘림 |
| 대비 · 라벨 · 터치 타깃 | WCAG AA 대비비, label-input 연결, 24px(SC 2.5.8) |
| 폼 보호 | 작성 중 이탈 경고, 모달 이탈 가드, 검증 실패 시 포커스 이동 |
| 도메인 검증 | 날짜·시간, 일괄 수정, 페이징 경계, 학생인건비, 연구노트, 집행 결재, 마감 알림, 자원예약, 전역 검색 |
| 표 도구 · 화면 설정 | 컬럼 폭 조절·정렬, 계정 저장(다른 기기·다른 계정 격리) |
| 표 표시(폭 변화) | 4개 폭 × 21 화면의 셀 잘림·머리글 접힘·카드 밖 넘침, 머리글 정렬이 실제로 순서를 바꾸는지, 키보드 정렬 |
| 자리비움 | 자리를 비운 동안 근무시간이 늘지 않고 복귀하면 다시 늘어나는지 |
| AI 멘토 | 응답 품질 벤치마크(15 시나리오 · 154 규칙), 화면 권한 경계, 상시 대화, 지도철학 인터뷰, 서비스 중단 시 동작 |
| 구성원 이름 | 퇴사·삭제된 구성원의 이름 표시 |
| 첨부 보안 | 업로드 형식·크기, 다운로드 인증, 응답 헤더, 로그인 시도 제한 |
| 동시 편집 | 낙관적 잠금(409) 동작 |

판정 기준: `❌`(검증 실패) · `[BUG]`(시나리오 중단) · `[ERR]`(콘솔/HTTP 오류)가 하나라도 있거나,
묶음이 끝까지 돌지 못하면 실패.

## 규칙

- **검증이 남긴 상태는 검증이 되돌린다.** 계정에 저장되는 설정(컬럼 폭·정렬), 예약, 로그인 실패
  카운터처럼 다음 회차에 영향을 주는 것은 각 묶음이 끝내면서 정리한다. 그러지 않으면 두 번째
  실행부터 앞 회차의 흔적 때문에 엉뚱한 곳이 실패한다.
- **판정은 전체 로그로 한다.** 화면에는 묶음별 끝 몇 줄만 보이므로, `run-all.sh` 는 `out/regress.log`
  전체를 훑어 판정한다.
- 새 동작을 추가하면 `scripts/` 에 검증도 함께 넣고 `run-all.sh` 에 등록한다.
